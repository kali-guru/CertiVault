How the workflows fit together

  1. Register

    Validate identity fields → hash password → generate RSA key → sign CSR → issue certificate → encrypt private key.

  2. Sign and verify

    Owner uploads → unlocks key → signs exact bytes → shares document and evidence → verifier checks certificate, signer and signature.

  3. Encrypt and deliver

    Select recipient → validate certificate → generate AES key → encrypt document → wrap key → recipient authorizes and decrypts.

  4. Manage trust

    Issued certificates remain active until expiry or revocation. Every protected cryptographic operation rechecks current status.

Know the limitations.

This educational system uses a single online CA and application-side key unlocking. It has no HSM, public trust, OCSP, signed CRL, trusted timestamp or independent security audit. Original uploads are private but stored unencrypted. A compromised server can intercept passphrases during use.
